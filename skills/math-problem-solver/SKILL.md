# 📐 Mathematics Problem-Solving Framework

## The 4-Step Problem-Solving Process

### Step 1: Understand the Problem
- Read the problem 3 times
- Identify what is given (G) and what is asked (A)
- Paraphrase in your own words
- Identify the domain (algebra, calculus, statistics, geometry)

**Socratic Questions:**
*"What information is provided?"*
*"What exactly are we solving for?"*
*"Can you restate this in simpler terms?"*

### Step 2: Devise a Plan
- Identify the concept(s) involved
- Choose the appropriate formula or method
- Break down into smaller steps
- Estimate the answer range

**Socratic Questions:**
*"What formula might apply here?"*
*"Have you seen a similar problem before?"*
*"What would happen if we tried X?"*

### Step 3: Carry Out the Plan
- Execute each step carefully
- Show all work
- Check for arithmetic errors
- Use proper notation

**Socratic Questions:**
*"Why did you choose that approach?"*
*"What if we did this step differently?"*
*"How did you get that number?"*

### Step 4: Look Back and Reflect
- Verify the answer (substitute back)
- Check for reasonableness
- Identify what you learned
- Consider alternative methods

**Socratic Questions:**
*"Does this answer make sense?"*
*"How would you solve this differently next time?"*
*"What concept did this problem illustrate?"*

## Specific Mathematical Domains

### Algebra
**Key Skills:**
- Equation solving (linear, quadratic, systems)
- Factoring and expanding
- Exponents and logarithms
- Functions and graphs

**Common Pitfalls:**
- Sign errors in operations
- Forgetting to apply operations to both sides
- Incorrect order of operations
- Domain restrictions (division by zero, logarithms)

**Practice Strategy:**
1. Master one type of equation at a time
2. Check solutions by substituting back
3. Graph to verify solutions visually

### Calculus
**Key Skills:**
- Limits and continuity
- Derivatives (rules and applications)
- Integrals (indefinite and definite)
- Differential equations

**Common Pitfalls:**
- Chain rule mistakes
- Integration by parts errors
- Sign errors in definite integrals
- Forgetting +C in indefinite integrals

**Practice Strategy:**
1. Memorize derivative and integral rules
2. Practice identifying which rule applies
3. Always check with the reverse operation

### Statistics
**Key Skills:**
- Descriptive statistics (mean, median, mode, variance)
- Probability rules
- Hypothesis testing
- Regression analysis

**Common Pitfalls:**
- Confusing correlation with causation
- Incorrect sample size calculations
- Misinterpreting p-values
- Applying wrong test type

**Practice Strategy:**
1. Understand the question before choosing the test
2. Draw the distribution
3. Interpret results in context

### Geometry
**Key Skills:**
- Euclidean geometry theorems
- Coordinate geometry
- 3D geometry
- Trigonometry

**Common Pitfalls:**
- Misreading diagrams
- Wrong units
- Angle relationships
- Forgetting to prove steps

**Practice Strategy:**
1. Draw a clean diagram
2. Label everything
3. Work from known to unknown

## Mnemonic Devices for Math

**For Derivatives:**
- "Power down" = derivative of x^n is n·x^(n-1)
- "Log rules" = log(ab) = log(a) + log(b)

**For Trigonometry:**
- "SOH CAH TOA" = Sine = Opposite/Hypotenuse, etc.
- "All Students Take Calculus" = ASTC for quadrant signs

## Common Mistakes and How to Avoid Them

| Mistake | Prevention |
| :--- | :--- |
| **Arithmetic errors** | Show all steps, use calculator sparingly |
| **Misreading the question** | Highlight key terms, re-read before solving |
| **Wrong formula** | Write down the formula first, check conditions |
| **Skipping steps** | Write every step, even if it seems obvious |
| **Not checking answers** | Substitute back, check reasonableness, use unit analysis |

## Exam Strategies for Math

1. **Scan the exam first** - 5 minutes to identify easy problems
2. **Solve what you know** - Build confidence and momentum
3. **Show your work** - Partial credit is better than no credit
4. **Time management** - Don't get stuck on one problem
5. **Check your answers** - If time allows, review your work
6. **Formulas page** - Know what's provided and what to memorize
